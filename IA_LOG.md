# Registro de Uso de IA — Zona Zero

## Interação 01 — Planejamento Inicial e Estrutura Git
- **Problema:** A equipe nunca havia desenvolvido um projeto integrando Java, Banco de Dados e Git em trio, e precisava organizar o escopo mínimo e a divisão de papéis.
- **Prompt:** Como estruturar um mini-RPG em Java com persistência em banco de dados e controle de versão em trio seguindo os requisitos de POO?
- **Sugestão da IA:** Criar um jogo de turnos no console com tema pós-apocalíptico (Zona Zero), utilizando classe abstrata `Personagem`, herança para classes jogáveis (`Soldado` e `Medico`) e inimigos (`ZumbiComum` e `Mutante`), além de pastas separadas `src/` e `sql/`.
- **Decisão do grupo:** Aceitamos a arquitetura proposta e definimos o sistema de ataque crítico como mecânica autoral do grupo.
- **Teste realizado:** Criamos o repositório público no GitHub, adicionamos os três colaboradores e validamos os primeiros commits de estrutura.
